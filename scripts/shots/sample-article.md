# 把公众号排版做成本地工具，我改了三个决定

写给每一个在公众号后台反复复制粘贴的人。

## 一、排版不该在复制这一步丢失

公众号会剥掉 `<style>` 标签，这是所有第三方排版工具的第一道坎。解法只有一个：**把样式全部内联到元素上**。

- CSS 内联
- 伪元素实体化（`::before` / `::after` 转成真实节点）
- CSS 变量解析

> 这三步做完，粘过去的东西才和你在本地看到的一致。

## 二、密钥不该离开你的电脑

AppSecret 只写本机的 `server/config.json`，界面永远只显示后四位。没有云端，没有托管。

## 三、工具应该长在你的习惯里

```js
// 复制与发布共用同一条管线
const html = wechatifyArticle(rendered, theme);
await copyHtmlToClipboard(html);
```

一周写三篇的人，不需要一个新平台，只需要一个不用切换窗口的地方。
