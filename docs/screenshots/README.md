# 产品截图

全部来自**真实运行的应用**（1920×1080 @2x 截取），不是设计稿、不是拼图。

## 目录

```
screenshots/
├── raw/            2x 原图（3840×2160 或 1566×1976），源文件
└── xiaohongshu/    已排版好、可直接发布的尺寸
    ├── 4x5/        1080×1350，竖版（预览区、手机预览）
    └── 16x9/       1920×1080，横版（工作台、功能展示）
```

## 每张图是什么

| 文件 | 内容 |
|---|---|
| `16x9/01-工作台全景` | 默认主题下的双栏工作台：左 Markdown、右实时预览 |
| `16x9/02-只写Markdown` | 编辑器区域特写（工具栏、行号、语法高亮） |
| `16x9/03-自定义主题面板` | 「主题编辑」抽屉：字号/行距/段间距/首行缩进/配色 |
| `16x9/04-一键进草稿箱` | 发布弹窗：标题、作者、摘要、封面、账号（账号 ID 已模糊） |
| `16x9/05-片段库` | 片段库面板 |
| `4x5/01-排版效果-编辑部手记` | 「编辑部手记」主题的完整排版效果 |
| `4x5/02-手机预览` | 手机宽度下的阅读效果 |
| `4x5/03-排版效果-东方笺谱` | 「东方笺谱」主题 |
| `4x5/04-排版效果-黑金奢华` | 「黑金奢华」主题 |
| `4x5/05-排版效果-包豪斯` | 「包豪斯」主题 |

## 重新生成

```bash
npm start                              # 需要应用跑在 :3000
node scripts/shots/capture.mjs         # 截 2x 原图到 raw/
node scripts/shots/capture-extras.mjs  # 补：主题面板 + 手机预览
bash scripts/shots/make-sizes.sh       # 出 4:5 / 16:9 两套尺寸
```

`make-sizes.sh` 会用 `boxblur` 把发布弹窗里的账号 ID 抹掉——对外发图不露内部标识。
